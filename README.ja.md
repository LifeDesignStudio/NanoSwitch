# NanoSwitch

[English](README.md) · 日本語

**すべてのウィンドウを見渡し、ひと操作で切り替え。**

macOS 標準の Cmd+Tab は「アプリ」を順に切り替えます。
NanoSwitch はすべての**ウィンドウ**をサムネイルのグリッドで表示し、目的のウィンドウへ直接ジャンプできます。

![NanoSwitch](https://github.com/user-attachments/assets/a96eb9e6-ea74-4990-b048-ecaf70e0b275)

---

## 使い方

`Cmd+Tab` を押す → サムネイルのグリッドが表示 → Tab または矢印キーで選択 → Cmd を離して切り替え。

新しいショートカットを覚える必要なし。設定も不要。ただ良くなった Cmd+Tab です。

---

## 特長

- **ウィンドウ単位の切り替え** — アプリ単位ではなく、開いているウィンドウをすべて表示
- **サムネイルのライブプレビュー** — 切り替える前に中身が分かる
- **現在の Space に集中** — いま使っているデスクトップのウィンドウを表示。現在の Space のウィンドウが 2 枚未満のときは `Cmd+Tab` が標準スイッチャーに切り替わり、他の Space のアプリにも到達できる
- **即時表示** — まずアイコンが瞬時に出て、サムネイルは背後で読み込み
- **軽量** — メニューバーに常駐し、静かにバックグラウンド動作、ログイン時に自動起動
- **ウィンドウを直接閉じる** — サムネイルにホバーして × をクリック、または `W` キー

---

## 動作要件

- macOS 14.6 以降
- **アクセシビリティ**権限 — Cmd+Tab の横取りに必要
- **画面収録**権限 — NanoSwitch の価値であるサムネイル表示に必要

どちらの権限も初回起動時にダイアログで求められ、アプリを再起動せずに付与できます。

> 画面収録を許可しないと、NanoSwitch はアイコン表示に留まり、標準の Cmd+Tab とほとんど変わりません。本来のウィンドウプレビューを得るには許可してください。

## インストール

1. [Releases](../../releases/latest) から `NanoSwitch.dmg` をダウンロード
2. DMG を開き、`NanoSwitch` を `Applications` フォルダに**ドラッグ**
   > ⚠️ システムの `/Applications` に入れてください（`~/Applications/` は不可）。ユーザーの Applications フォルダから動かすと、画面収録を許可してもサムネイルがサイレントに失敗します。
3. `/Applications` から起動し、アクセシビリティと画面収録を許可

以降の更新は自動（Sparkle）です。メニューの **Check for Updates…** からも確認できます。

## キー操作

| 操作 | キー |
|------|------|
| スイッチャーを開く / 次のウィンドウ | `Cmd+Tab` |
| 前のウィンドウ | `Cmd+Shift+Tab` |
| 移動 | 矢印キー |
| 切り替え | Cmd を離す |
| キャンセル | `Escape` |
| 選択中のウィンドウを閉じる | `W` |

**Launch at Login** の切り替えや **About / Help** は、メニューバーアイコンから開けます。

## トラブルシューティング

**サムネイルが出ない / アイコンしか表示されない**

まず **システム設定 → プライバシーとセキュリティ → 画面収録** で許可してください。
許可済みなら、`NanoSwitch.app` が `/Applications/`（`~/Applications/` ではない）にあるか確認を。ユーザーの Applications フォルダから動かすと画面収録のサムネイルがサイレントに失敗します。

**Cmd+Tab が横取りされない**

メニューバーアイコンを開き、「Cmd+Tab を横取りできていません」の警告が出ていたら、**システム設定 → プライバシーとセキュリティ → アクセシビリティ** で NanoSwitch を一度削除して再追加し、アプリを再起動してください。

**macOS の Gatekeeper にブロックされる**

`NanoSwitch.app` を右クリック → **開く**、または **システム設定 → プライバシーとセキュリティ** で **このまま開く** をクリック。
